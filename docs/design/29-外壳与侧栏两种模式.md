# 29 外壳：侧栏两种模式，工作区嵌入面板

> 状态：已实施（2026-11-09）。起因：Solo 页上线后左边有两列（App 侧栏 + Solo 自己的会话栏），浅色主题下侧栏仍是深色，和工作区割裂。参考：团队协作类 AI 交付产品常见的外壳——侧栏顶部分"协作 / 个人"两种模式，侧栏跟随主题，工作区是嵌在外壳里的圆角面板。

## 结论

1. **侧栏分两种模式：Solo 和空间。** Solo 是和管家直接对话，侧栏放新对话、会话和动态，跨空间；空间是项目导航，侧栏放空间选择、总览 / 需求 / 待办 / 知识库 / Workflow / 评测 / 空间设置和最近的需求。Solo 页不再自带一列会话栏，左边只有一列。
2. **模式就是路由。** `/solo` 是 Solo 模式，其他页面是空间模式；点模式标签跳到这个模式上次停留的地址（Solo 回到原会话和焦点，空间回到原页面），所以来回切不丢位置。
3. **侧栏跟随主题。** 浅色是比工作区略深的暖灰，深色是比工作区略亮的石墨；侧栏文字直接用 `--text` 三级。原来"两套主题都是深色导轨"的规定作废。
4. **工作区是嵌入面板。** 离窗口上、右、下各 8px，14px 圆角，一圈 `--rail-border` 细边；面板自己滚动，顶栏吸在面板顶部。管家停靠面板在宽屏时是并排的第二块面板，窄屏浮在上面。窄于 900px 时面板铺满窗口，侧栏收成抽屉。

- 顶部一行：节拍蜂 + 产品名 + 图标按钮。"在旁边问管家"（⌘J，停靠面板）只在空间模式出现，Solo 本身就是管家。
- 模式标签是文字标签，当前项加粗并带一道下划线；收起侧栏（⌘B）时换成两个图标。
- 空间选择是一个带字母标的选择框；节拍橙仍只用在导航的"当前位置"刻度和角标上。
- Solo 模式的会话列表是 `pages/solo/rail.tsx`，跟 Solo 页一起按需加载；选中状态都在地址里（`?thread=`、`?side=feed`），Solo 页按地址变化重置焦点跟随和草稿。

## 2 尺寸与色值

| 项 | 值 |
| --- | --- |
| 侧栏宽 | 248px，收起 60px |
| 面板外边距 | `--shell-gap: 8px`（窄屏 0） |
| 面板高 | `--panel-h: calc(100dvh - 2 × gap)`；页面里原来写 `100vh` 的定高都改用它 |
| 外壳底 | 浅 `oklch(0.948 0.004 80)`，深 `oklch(0.2 0.006 75)` |
| 侧栏 hover / 当前 | 墨色 5.5% / 8.5%（深色用纸色 6% / 9.5%） |
| 侧栏输入框底 | `--rail-field`：浅 `oklch(0.985 …)`，深 `oklch(0.235 …)` |

## 3 不做

- 不加第三种模式（比如"个人待办"）；待办仍在空间模式里按空间看，跨空间的"等你决定"在 Solo 首页。
- 不做侧栏宽度拖拽。
