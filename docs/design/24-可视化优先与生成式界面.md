# 24 可视化优先与生成式界面

> 状态：M4.5（M5 之前）。起因：用户走查 M4 后仍觉得"界面展示、交互动效不满意"，并给了两个参考：
> 秘秘 Mimi super agent 的功能先导视频（B 站 BV1vix26sEzR）与 intelligence-ui（Agent 输出 JSON 组件树、宿主校验修正后渲染）。

## 结论

1. **每页一个视觉主角，文字只做结论。** 总览的主角是"交付泳道"（一需求一行，阶段格逐格点亮），不是表格；页头说明、建议胶囊、卡片说明都限字数。
2. **管家回答 = 不超过 3 句结论 + 可视化块。** 块是一套面向交付领域的小组件（读数、泳道、条形、表格、清单、时间线、提示、按钮），模型用 `show` 工具给出，服务端校验修正；进度 / 风险 / 待办有服务端预设（真实数据确定性展开），不靠模型编数字。
3. **组件按容器宽度变形，不按视口。** 停靠面板打开时主区只有 ~1000px，卡片里只有 ~600px：表格列、读数、泳道都用容器查询切换形态，任何宽度不出现"一字一行"。

## 参考里值得学的（只取与交付控制台相关的）

| 参考 | 看到的 | 我们怎么用 |
|---|---|---|
| 秘秘日报 | 一条回复里是表格 + 三格读数（彩色数字）+ 进度线 + 可勾选清单 + "先放着 / 定了"按钮；字幕："不是一段长文，是能勾选、能点的界面" | 管家块；总览"等你决定"每项直接给决定按钮 |
| 工坊 | 一句话派活后，右侧按任务列出泳道，每格一个检查点，"进度不靠汇报，跟着提交和测试结果走" | 交付泳道：格子状态只来自运行事件，不来自 Agent 自述 |
| 每一包一条分支 | 并行任务从主线分叉、各自推进、依次合回 | 运行页（后续）：并行节点的时间泳道 |
| 摘要不算证据 / 排序每一分都说得清 | 检索结果按来源分道、每条有分数条 | 知识库检索结果的分数条（已有命中分，补可视化） |
| 这一轮发给模型的内容 | 上下文组成 + 占比条 | 已有上下文来源堆叠条，保持 |
| 整体气质 | 冷灰底 + 白色大圆角面板 + 很轻的阴影；小字号、留白多；一个主色 | 保留"节拍控制室"身份（石墨导轨、节拍橙），面板改大圆角、去硬描边、加留白 |

intelligence-ui 的做法（组件协议 + 发布前校验与自动修复 + 结构化回传用户操作）直接对应我们的 `StewardBlock` + `steward/blocks.ts` + `StewardAction`。
差别：我们的组件是领域组件（泳道、读数），不是通用 Stack / Grid；按钮不直接执行写操作，只能追问、跳转或打开预填的命令表单（写操作仍走提案 / 原因确认）。

## 协议

见 `packages/core/src/api.ts` 的 `StewardBlock`（注释里有上限与校验规则）。要点：

- 一条消息 ≤ 6 块、不嵌套；块显示在正文之后；流事件 `blocks` 每次给全量。
- `ref` 必须是调用者看得见的对象，看不见的去掉 ref 保留文字；`command` 按钮必须在命令表里。
- 预设：`space_progress`、`requirement_progress`、`risks`、`attention`——服务端用真实数据展开。
- 离线（没配模型）时，问进度 / 风险 / 待办也返回预设块。

## 界面规则（ux-audit 检查其中能静态检查的）

- **字数预算**：页头说明 ≤ 24 字（能用数字表达的放读数，不写句子）；管家建议 ≤ 14 字且不重复当前对象名；卡片说明一行。
- **容器查询**：列表、读数条、泳道、表格必须声明 `container-type: inline-size`，按容器宽度切换形态（泳道行 ≥ 680px 三列、否则泳道换到标题下；总览 ≥ 900px 右侧"等你决定"、≥ 1200px 加宽到 340px）；禁止只靠固定列宽。
- **读数**：flex 换行 + 按容器宽度定列数（≥ 860 全部一行 / ≥ 520 ceil(n/2) / ≥ 300 至多 3 / 更窄 2），最后一行自动撑满，不允许单独一格挂在第二行左边；彩色数字只表达状态，值为 0 不着色。
- **表面**：卡片圆角 14px、浮层 18px；静止卡片只用一圈极淡描边 + 很轻的环境阴影；卡片内边距 20px。
- **动效**：
  - 泳道首次出现时格子从左到右依次点亮（每格 18ms，最多 12 格），之后状态变化只做颜色过渡；运行中的格子跟 `--takt` 节拍；
  - 管家块"组装"：逐块淡入上移 4px（间隔 60ms），块内条形 `scaleX` 从 0 长到值；
  - 读数用 `CountUp`；条形、进度一律 `transform`，不动画宽高；
  - reduced-motion：只保留透明度。

## 范围与顺序

1. 协议 + 后端（Codex：`m45-steward-blocks`）。
2. Web：块组件库（`components/viz/`）与渲染；总览改"简报"（读数 + 交付泳道 + 等你决定）；需求表容器查询；停靠面板欢迎页（问候 + 迷你读数 + 短建议 + 去重的最近会话）；全局表面 token。
3. 走查：1280 / 1728 + 停靠面板 / 1024 三种宽度 × 深浅主题截图；文字预算全站过一遍。
4. 之后（M5 期间穿插）：运行页时间泳道、知识库检索分数条。
