# 25 运行态可读与回访

> 状态：M4.6（M5 之前）。参考：MeowCode（动作清单、回合改动卡、检查点）与 Agent HUD（每个 Agent 一个有状态的形象、进度光晕、渐进展开、"有新回复"卡、会话页迷你图）。
> 只借思路：MeowCode 是 GPL-3.0，Agent HUD 的形象用了第三方品牌图形，两者的代码与图形都不拷进本仓库。

## 结论

1. **动作先说动词。** 工具调用一律写成"动词 + 对象 + 结果"：`读取 src/export/csv.ts`、`运行 npm test · 通过`、`修改 csv.ts +12 −3`；连续同类合并成 `读取 3 个文件 ×3`。不同 harness 的工具名（Read / read_file / command_execution …）归到同一张动词表。
2. **Agent 有脸。** Agent 节点和管家用同一个原创小形象（圆角方块 + 两只眼），四种状态一眼可辨：待命（闭眼）、干活（睁眼、按节拍眨眼）、求助（头顶 `!` / `?`）、完成（眯眼笑）；失败是 `✕`。颜色按 harness 稳定分配。
3. **读数带趋势。** 读数格加 14 天迷你折线，需求行加"最近 12 次运行"的迷你柱（高 = Token，色 = 结果）。
4. **离开了也知道什么时候回来。** 标签页标题带待办数、图标带状态点；运行结束 / 新的等你决定弹一张带去处的卡；开了浏览器通知且页面在后台时发系统通知。
5. **动效守规矩。** 标签页隐藏时所有无限动画暂停；条形用 clip-path 从左打开（不缩放，圆角不变形）；读数标签在条形长到大半后再淡入；首屏已有的内容随容器一起出现，之后才到的单独入场。

## 1 动作行

| 动词 | 归类规则（工具名，大小写不敏感） | 结果词 |
|---|---|---|
| 读取 | read / read_file / cat / view / open | — |
| 搜索 | grep / glob / list / find / search（不含 web） | 能数出时 `N 处` |
| 修改 | write / edit / multiedit / apply_patch / file_change / replace | 能从补丁数出时 `+A −D` |
| 运行 | bash / shell / command_execution / exec / run | `通过` / `失败` |
| 访问 | web_search / web_fetch / fetch / http | — |
| 检索 | kb_query / knowledge | 能数出时 `N 条命中` |
| 派给 | task / agent / subagent | — |
| 调用 | 其它（MCP `server.tool` 等） | — |

- 对象从输入里取：JSON 输入取 `file_path / path / pattern / command / query / url`，否则取第一行；路径只显示末两段，完整值在悬停提示里。
- 合并：同一节点里连续、同动词的调用合并成一行 `×N`，展开看每一条。失败的调用不合并（要单独看见）。
- 管家工具同样处理：`查看 需求列表 · 7 条`、`查看 REQ-002 状态`、`检索「导出权限」· 3 条命中`、`起草 提案「…」`、`转达 REQ-002 的 Lead`、`绘制 2 个可视化块`。
- 用在：管家回答里的动作清单、运行页底部滚动条、节点抽屉"过程"里的工具调用。

## 2 Agent 形象（AgentMark）

| 状态 | 来自 | 样子 | 动效 |
|---|---|---|---|
| 待命 | pending / ready / skipped / cancelled / stale | 闭眼（两条短横） | 静止 |
| 干活 | running；管家流式回复中 | 睁眼 | 每 4 拍眨一次眼、随节拍轻微起伏 1px |
| 求助 | waiting_human（`!` 审批 / `?` 回答）、blocked（`!`） | 眼睛上看 + 头顶符号，琥珀色 | 符号每 2 拍轻跳一次 |
| 完成 | succeeded | 眯眼笑（两道弧） | 静止 |
| 失败 | failed | `✕` 眼 + 红色符号 `✕` | 静止 |

- 原创图形，不用任何品牌标志；颜色按 harness 名字哈希到图表色板（同一个 harness 全站同色），harness 名字在悬停提示与节点副标题里。
- 只有"干活 / 求助"会动；`prefers-reduced-motion` 下全部静止但形状照样区分状态；标签页隐藏时暂停。
- 用在：运行页 Agent 节点（替换原来的 Agent 图标）、管家头像、停靠面板标题。运行中的细分（读 / 改 / 跑 / 长步骤 ≥15s / 压缩中）放到 M5，与时间泳道一起做。

## 3 趋势

- 协议（全部可选）：`RequirementSummary.recentRuns`：最近 12 次运行 `{ runId, status, startedAt, tokens, kind }`；`ProjectOverview.totals.daily`：最近 14 天 `{ day, runs, tokens }`（按运行开始日计，只算看得见的需求）。Token 与需求累计同口径：来自事件（`RequirementMetrics.runUsage`），不读节点状态。
- 读数格：`进行中` 配"每日运行次数"、`累计 Token` 配"每日 Token"，画在格子右上角、与标签同一行（不挤数字），格子太窄就不画；14 天里一次运行都没有时不画；悬停写明口径。
- 需求行：Token 读数旁画最近运行的迷你柱，失败红、等人琥珀、运行中节拍橙、成功中性灰；任务运行（Lead 派发）画得更淡（高度照样表示 Token）。

## 4 回访

- **脉搏**：外壳每 15 秒（页面在后台时 60 秒）取一次当前空间总览；和上一次比，有变化才让页面刷新（`invalidate`），没变化什么也不做。
- **标签页**：标题 `(2) taktflow 控制台`（括号里是等你决定的数量）；图标三态：空闲、运行中（节拍橙）、等你（右上角琥珀点）。
- **卡片**：某需求的运行结束 → `REQ-002 运行结束 · 已交付` [看运行] [回到需求]；出现新的等你决定 → `REQ-002 等你：<一句话>` [去处理]。同一事件只提示一次；首次加载不提示。
- **系统通知**：管家偏好里开了浏览器通知、权限已允许、且页面在后台时才发；点击通知回到页面并跳到对应位置。

## 5 动效细则（补充 DESIGN.md Motion）

- 隐藏即停：`document.hidden` 时根元素带 `data-tab-hidden`，所有 `animation-play-state: paused`。
- 到达规则：首屏已有的内容随容器一起出现（列表错峰一次）；之后到达的才单独入场（新消息上移淡入、新行闪一下）；轮询刷新不重播入场。
- 条形：`clip-path: inset(0 X 0 0 round r)` 从左打开 520ms；读数文字在 +360ms 后淡入 160ms。迷你折线首次出现时描线 400ms，数据更新直接换形不重播。

## 6 阶段轨道与页面层次（M4.6 补充）

阶段进度原来是一排扁平的分段条，看不出"走到哪、正在干什么、下一站是谁"。改成一条**阶段轨道**（`StageRail`），需求页头部与运行页头部共用（运行页用小一号、不带说明句）。

- **一条轨道，站点穿在上面。** 完成段实色；当前阶段从站点往下一站伸出一段传送带，长度 = 本阶段完成比例（至少露头、离下一站留空隙），头上一颗节拍橙光点；没走到的段是虚线。当前在最后一站时没有这一段。
- **站点说状态，不只靠颜色。** 完成白勾、进行中节拍点、等人暂停双竖（琥珀底）、失败叉、未开始虚线圈 + 序号；当前站放大一档并带外环。
- **站点下面说细节。** 阶段名、节点刻度（一个节点一格：完成绿、当前那格按状态着色，超过 12 个改细进度条）、`done/total`；当前阶段加一句 `在跑：<节点标题>` / `等你：…` / `失败：…`（运行中扫光）。容器窄于 520px 去掉刻度。
- **入场讲一遍进度。** 轨道从左铺开，走到哪站那站弹亮、勾描出来；铺到当前站后它才亮、外环开始呼吸，当前段伸出、光点冒出。全部完成时一道光扫过整条轨道、站点依次轻跳。轮询刷新只做过渡（轨道伸长、站点换色），不重播入场。
- **同一页面的其他层次。** 页面直接子块分层入场（页头 → 建议 → 阶段 → 决策 → 预算 → Tab）；侧栏与产物列表的选中底色是一个滑块，换选中时滑过去；点 Tab 内容顺着方向滑入；换产物时页头、元信息、正文依次出现；进度条首次出现从左打开。
- 规格数值见 DESIGN.md「阶段轨道与页面层次」。

## 不做 / 推后

- 运行中细分状态、子 Agent 甘特（时间泳道）、上下文窗口曲线、等人限时与交还、转达回执、检查点与回退预览、节点改动卡 → M5（与 doc 21 的事件 / 快照一起）。
- workflow 编辑器的打回标签、角色工具胶囊、热力图、logo 与节拍摆锤加载 → 之后的打磨批次。
- 屏幕边缘悬浮 HUD、手表 App：不在网页控制台范围内；"一瞥 → 展开 → 处理"的思路落在顶栏运行指示与停靠面板。
